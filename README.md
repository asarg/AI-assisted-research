# ASARG AI-Assisted Research

This repository is a place for the Algorithmic Self-Assembly Research Group (ASARG) to share the AI-assisted papers and results we generate.

We want to make this work available as soon as possible. When much of a paper is generated by AI, "authorship" becomes a bit muddied. For now, we're using this repository as an interim place to share the work rather than immediately posting it to arXiv.

## What's in each paper folder?

Each paper has its own folder under `papers/`. Following an approach described by Erik Demaine, we're organizing each result around three things:

- **`paper.pdf`** — A human-readable explanation of the problem and the main theorems.
- **`lean-verification/`** — Formal Lean code proving the results in the paper, along with the files and instructions needed to check it.
- **`slop.pdf`** — An LLM-generated informal proof and technical overview. This is mainly intended to be given to your own LLM so you can ask questions about the work.

Some entries may still be in progress. We'll note which parts are available and what has been formally verified.

## Adding a paper

Start with the [paper template](papers/_template/). ASARG members with write access can do this in their browser:

1. **Open the editor.** While viewing this repository on GitHub, press the `.` key.
2. **Copy the template.** In the file explorer, right-click `_template` and choose **Copy**. Right-click its parent `papers` folder and choose **Paste**. Rename the copy to a short name for your paper, such as `crn-reachability`.
3. **Add your files.** Drag `paper.pdf` and `slop.pdf` into your new paper folder, and put the Lean project inside its `lean-verification/` folder. Add whichever parts are ready.
4. **Fill in the READMEs.** Replace the placeholders in your paper’s README. If you have a Lean project, fill in its checking instructions too. Say what is available, what has been checked, and what is still unfinished.
5. **List your paper.** Add a line under **Papers** in this root README, using your actual folder name:

   ```markdown
   - [Your paper title](papers/crn-reachability/)
   ```

6. **Save your changes.** Open **Source Control** in the left sidebar, click **+** next to **Changes**, enter a short commit message, and choose **Commit & Push**. If the repository requires pull requests, use a new branch and open a pull request.
