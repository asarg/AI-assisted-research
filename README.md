# ASARG AI-Assisted Research

This repository is a place for the Algorithmic Self-Assembly Research Group (ASARG) to share the AI-assisted papers and results we generate.

We want to make this work available as soon as possible. When much of a paper is generated by AI, "authorship" becomes a bit muddied. For now, we're using this repository as an interim place to share the work rather than immediately posting it to arXiv.

## What's in each paper folder?

Each paper has its own folder under `papers/`. Following an approach described by Erik Demaine, we're organizing each result around three things:

- **`paper.pdf`** — A human-readable explanation of the problem and the main theorems.
- **`lean-verification/`** — Formal Lean code proving the results in the paper, along with the files and instructions needed to check it.
- **`slop.pdf`** — An LLM-generated informal proof and technical overview. This is mainly intended to be given to your own LLM so you can ask questions about the work.

Some entries may still be in progress. We'll note which parts are available and what has been formally verified.
